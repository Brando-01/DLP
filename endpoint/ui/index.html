Qué demuestra cada prueba

Una copia bloqueada por esta pantalla no demuestra bloqueo de una copia realizada directamente desde el Explorador. Para restringir un canal completo en Windows, utiliza los controles generales opcionales y verifica su efecto con un dispositivo de prueba.

Los destinos iniciales USB y red son directorios locales ficticios. Para usar un USB real o una ruta UNC, configura el destino y marca lab: false. El receptor HTTP se inicia con npm.cmd run receiver.

Conector del navegador

El complemento consulta al agente local antes de liberar las interacciones manuales que soporta.

Instalación

  1. Ejecuta npm.cmd run extension:build.
  2. En Chrome o Edge, abre la página de extensiones, activa el modo de desarrollador y carga extension/dist/chromium/ sin empaquetar.
  3. Para pruebas en Firefox, abre about:debugging#/runtime/this-firefox y carga temporalmente el manifiesto de extension/dist/firefox/.
  4. Abre las opciones del complemento y registra la dirección local y el token de vinculación.

El token es exclusivo del navegador: no permite administrar carpetas o destinos. No lo incluyas en capturas ni lo publiques.

Interacciones cubiertas

Selección manual de archivos mediante los campos compatibles, pegado de texto y arrastre de archivos. Las APIs programáticas, los componentes especiales de algunas páginas y las aplicaciones ajenas al navegador pueden requerir controles adicionales. Prueba cada escenario antes de atribuirle cobertura.

Con cierre ante fallo, si el agente no responde el complemento retiene la interacción. Eso es una restricción por indisponibilidad, no una detección de información sensible.

Configuración del agente

Solo esta interfaz local puede administrar la configuración. Los cambios no aplican por sí mismos restricciones generales de Windows.

Carpetas protegidas

Al iniciar se usa una carpeta de laboratorio con información ficticia. Puedes añadir Documentos, Escritorio, Descargas u otras rutas accesibles.

Modos por canal: audit detecta y permite; alert alerta y permite; enforce bloquea según el umbral. El portapapeles nativo es observación posterior; clipboardRemediation permite una limpieza reactiva, no una garantía de prevención.

Controles generales opcionales de Windows

El script endpoint/windows/System-Controls.ps1 prepara, aplica y restaura restricciones de escritura USB, salida SMB e impresión. Su acción predeterminada es mostrar el plan. La aplicación real requiere una terminal administrativa, afecta a todo el canal y debe probarse por separado.

No se modifican automáticamente el firewall, las políticas USB ni el servicio de impresión al arrancar este proyecto.
